База данных StudyHub

СУБД — PostgreSQL 18. Схема создаётся только SQL-скриптами из папки 'migrations'.

Как создать базу:

1. Создать пустую базу 'studyhub'.
2. Выполнить скрипты из 'migrations' по порядку номеров.
3. Для разработки можно добавить тестовые данные: 'test_data/create_test_data.sql'.
4. Удалить тестовые данные: 'test_data/clear_test_data.sql'.
