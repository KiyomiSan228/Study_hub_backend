База данных StudyHub

СУБД — PostgreSQL. Схема создаётся только SQL-скриптами из папки 'migrations'.

Как создать базу:

1. Создать пустую базу 'studyhub'.
2. Выполнить скрипты из 'migrations' по порядку номеров.
3. Для разработки можно добавить тестовых пользователей: 'test_data/test_data.sql'.
