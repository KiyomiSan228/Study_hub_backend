Запросы для бэкенда StudyHub

SQL-запросы для Dapper. Над каждым запросом — его имя (`-- RegisterUser: ...`).

Файлы: `auth.sql` — аккаунт, `tasks.sql` — задачи, `fire.sql` — костёр,
`focus.sql` — таймер, `notes.sql` — блокнот.

Правила:

1. Значения передаются только параметрами `@Имя`.
2. `@UserId` берётся из токена (`GetUserIdByToken`).
3. Колонки названы в snake_case (`completed_at`).
4. Телефон хранится в формате `+79991234567`.
5. Статусы и сложности — числа из справочников:
   сложность 1 Лёгкая, 2 Средняя, 3 Сложная;
   задача 1 Активна, 2 Выполнена, 3 Не выполнена;
   сессия фокуса 1 Активна, 2 Завершена, 3 Прервана.
6. Изменение, удаление и отметка задачи срабатывают только для активной задачи.
   Если ничего не изменилось, `GetTaskStatus` подскажет причину:
   нет строки — задача не найдена, статус 2 или 3 — задача уже отмечена.

Транзакции:

- регистрация: `RegisterUser`, `CreateFire`, `CreateAuthSession`
- выполнение задачи: `SetTaskStatus`, `UpdateFire`
